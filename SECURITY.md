# Security Policy

## Supported Versions

Currently, we are only supporting security updates for the 2.5.x suite of projects. Anything prior to 2.5.0 should be upgraded.

| Version | Supported          |
| ------- | ------------------ |
| 2.5.x   | :white_check_mark: |
| < 2.5.0 | :x:                |

## Reporting a Vulnerability

In order to report a security vulnerability please open a new Issue on this repository. It notifies the development team directly and we will investigate and reply with a comment to the concern. The level of vulnerability found will determine the mitigation efforts and follow up steps.
